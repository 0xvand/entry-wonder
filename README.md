## The entry

> The washing machine escapes two centimetres every cycle, so slowly only the rug has noticed.

`main.py` writes this sentence to `/output/entry.txt` (override the path with the `ENTRY_OUTPUT` environment variable for local testing).

## Why it should win

Everyone has found a washing machine slightly out of place after a spin cycle, but nobody frames it as what it is: an escape in progress, conducted at a speed only furniture can perceive. The sentence takes a real, checkable, everyday phenomenon and turns it at an angle the reader has not met before — the machine is not broken or noisy, it is *leaving*, and the rug is its only witness. The surprise lands in a single read, every word is doing work, and nothing in it floats free of the laundry room.
